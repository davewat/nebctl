Nebula Node

Run your Nebula network from your Mac.

Nebula Node puts your Mac on a Nebula network and gives you one console for all of it. nebctl sets up the lighthouse on your Linux server.

Download for Mac How to set it up

macOS 14 or later. Free.

Step 1

Install Nebula Node

  1. Download it, unzip it, and drag Nebula Node to Applications.
  2. In Terminal, clear the download flag (the app isn't notarized yet) and make it root's (it runs its tools as root):
sudo xattr -cr "/Applications/Nebula Node.app"
sudo chown -R root:wheel "/Applications/Nebula Node.app"

Step 2

Set up the lighthouse

SSH to a Linux server with a public IP and install nebctl:

curl -LO https://github.com/davewat/nebctl/releases/latest/download/nebctl-linux-amd64
sudo install -m 0755 nebctl-linux-amd64 /usr/local/bin/nebctl
sudo nebctl lighthouse

Press Enter to take the defaults. Then open UDP 4242 in the server's firewall, and run sudo nebctl ca sign to make a bundle for your Mac.

Step 3

Join your Mac

Open Nebula Node, click Set Up This Mac as a Node, and paste the bundle. It installs nebula and starts it at boot. Your Mac can then reach each host by name, like ssh lh.example.internal.

Step 4

Manage it all from one console

Click Open Admin Console in Nebula Node, then connect to your lighthouse over SSH.

Also: firewall rules, logs, and forwarding logs to your SIEM.

Linux only, or prefer the command line? See the README.
