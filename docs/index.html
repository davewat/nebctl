Join a host to your Nebula network with one paste.

nebctl sets up Nebula on Linux and macOS: the lighthouse every host checks in with, the certificate authority that signs each host, and the hosts that join. It asks plain questions, then writes the config, the service and the DNS for you.

Download Nebula Node for Mac Get the command-line tool

The Mac app needs macOS 14 or later. The command-line tool runs on any Linux with systemd, and on macOS.

From nothing to a working network

Set up the lighthouse once. After that, adding a host is two commands: one on the lighthouse, one on the host.

  1. On a server with a public address

    Set up the lighthouse

    It installs nebula, creates the certificate authority, signs its own cert and starts the service.

    $ sudo nebctl lighthouse

  2. On the lighthouse

    Sign a cert for the new host

    It prints a bundle: the host's cert and key, the lighthouses and the domain, in one block of text.

    $ sudo nebctl ca sign

  gets .nebula.example.com): mac01

  3. On the new host

    Paste the bundle

    It installs the cert, writes a config that nebula -test has passed, sets up DNS and starts nebula at boot.

    $ sudo nebctl node

Nebula Node, for the Mac

The third step, in a window. Paste the bundle, check the lighthouses and what other hosts may reach, and Nebula Node installs nebula, writes the config and starts it at boot. macOS asks for an administrator's password when it changes anything.

  • Would rather the private key never left this Mac? It makes a request for the lighthouse to sign instead.
  • Shows when the cert expires and whether nebula is running, with Start, Stop and Restart.
  • Runs the same nebctl as the command line, so both set up a Mac the same way.
Download Nebula Node for Mac

It isn't notarized by Apple yet. After moving it to Applications, run xattr -cr "/Applications/Nebula Node.app" once, or macOS refuses to open it.

What else it takes care of

The parts of running Nebula that are easy to get wrong by hand.

Names instead of addresses
ssh fe01.nebula.example.com works from every host. The lighthouse answers for the network's own domain, and each host sends only that domain to it, so everyday lookups are untouched.
Keys that stay where they were made
sudo nebctl request makes the key on the host and prints a request holding only the public half. The lighthouse signs it, and the private key never travels.
A checked install
nebula comes from the official slackhq/nebula releases and is checked against their checksums. sudo nebctl update moves a host to a new release and restarts it.
A security review of the lighthouse
The lighthouse faces the internet. sudo nebctl audit reviews its firewall, open ports, SSH, updates, kernel settings and accounts, and gives the commands that fix each problem.
Renewals at the same address
Sign the same name again and the host keeps its address and groups. nebctl status warns 30 days before a cert expires.
A config tested before it's used
Every new config has to pass nebula -test before it replaces the old one, so a typo never takes a host off the network.

Install the command-line tool on Linux

curl -LO https://github.com/davewat/nebctl/releases/latest/download/nebctl-linux-amd64
curl -LO https://github.com/davewat/nebctl/releases/latest/download/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
sudo install -m 0755 nebctl-linux-amd64 /usr/local/bin/nebctl
sudo nebctl

Install the Mac app

curl -LO https://github.com/davewat/nebctl/releases/latest/download/NebulaNode-macos.zip
curl -LO https://github.com/davewat/nebctl/releases/latest/download/SHA256SUMS
shasum -a 256 -c --ignore-missing SHA256SUMS
ditto -x -k NebulaNode-macos.zip /Applications
xattr -cr "/Applications/Nebula Node.app"

Running the same commands again updates to the newest release. The README walks through a lighthouse, Linux hosts and Macs question by question.

nebctl is on GitHub, where you can report problems and read the code.

Nebula itself is slackhq/nebula. nebctl installs its official releases and isn't affiliated with the Nebula project.
